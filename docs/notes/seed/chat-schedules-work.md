title: Chat does not code; it schedules jobs
tags: [core, chat]
updated: 2026-10-22
---

Discord jarvis-chat has no shell, files, systemd, or secrets. It talks to Nathan and creates jobs for agent-run / jarvis-jobs, which can change the system. Use !build / !fix, or a SCHEDULE block. Never claim a file was edited or a service restarted from chat.
