# Qwen3.8 27B Q4 at 128K and 256K context

Measured 2026-10-23 on the RTX 4090 (24.5 GB) with `scripts/benchmark_q6.py` against a scratch
`llama-server` on port 18080 (`jarvis-engine` stopped during the run, restarted afterwards, active).
Model: the `qwen3.8:27b` Ollama blob (Q4, 16.8 GB), same as the 64K benchmark. Flags identical to
`docs/benchmarks/qwen38-27b-q6-vs-q4-64k.md` except `--ctx-size`:
`--parallel 2 --kv-unified --cache-type-k q4_0 --cache-type-v q4_0 -fa on`.
Standard 657-token code-review prompt, 3 runs each, plus one long-context run (needle at the start
of a log-style prompt, question at the end).

| Metric | 64K (earlier) | 128K (131072) | 256K (262144) |
|---|---|---|---|
| VRAM, loaded idle | 18.9 GB | 20.4 GB | 22.6 GB |
| VRAM, peak during run | - | 20.4 GB | 22.7 GB |
| Prompt speed (657 tok) | ~1,700 tok/s | ~1,700 tok/s | ~1,150 tok/s |
| Decode speed (short prompt) | 48.2 tok/s | **47.8 tok/s** | **27.2 tok/s** |
| Wall, 1024 tokens | 21.8 s | 22 s | 38 s |
| Tool call (`bash`) | PASS | PASS | PASS |
| 3 small tasks | 2/3 | 2/3 | 2/3 (same capital-of-Australia FAIL) |
| Long prompt | - | 94,291 tok: 2,284 tok/s prefill, 37.2 tok/s decode, 43 s, needle PASS | 198,296 tok: 1,414 tok/s prefill, 20.1 tok/s decode, 143 s, needle PASS |

## Findings

- **128K is free**: speed matches 64K and leaves ~4 GB VRAM. Even with a 94K-token prompt in
  context, decode is still 37 tok/s.
- **256K costs half the speed**: decode drops from 48 to 27 tok/s on a short prompt (20 tok/s with
  a 198K prompt), and only ~1.9 GB VRAM is left (Whisper and other GPU users will not fit
  comfortably). This looks like the same VRAM-pressure cliff seen with Q6 at 98K; I did not confirm
  the layer split (the build prints almost no offload lines).
- Retrieval: the needle at the start of the prompt was found at both sizes (one needle, one run
  each; not a long-context quality eval).
- A first attempt with a 110K/230K-token prompt estimate got HTTP 400 on both (the script did not
  print the body; most likely the prompt exceeded the context). The estimate was fixed to 24 tokens
  per line and the long runs repeated with n=1.
- The small-task miss (capital of Australia) is the same at every context size, so it is the
  model/quant, not context.
- `systemd/jarvis-engine.service` is unchanged (`--ctx-size 98304`, Q6).

## Reproduce

    python3 -I -u scripts/benchmark_q6.py http://localhost:18080 3 110000   # 128K server
    python3 -I -u scripts/benchmark_q6.py http://localhost:18080 3 230000   # 256K server
