# Conversation notes

Where our conversations are kept, on this machine, so the agent can look
back at what was asked, decided and said.

| File | Written by | Content | In git |
|---|---|---|---|
| `agent-YYYY-MM-DD.md` | the coding agent, one `##` section per run | What Nathan asked, what was decided/built, what is left open | yes |
| `discord-YYYY-MM-DD.md` | `jarvis-chat`, automatically | Every Discord/voice exchange, verbatim | no (gitignored) |

The Discord log is verbatim and chatty, so it is kept out of git; the
agent's notes are the distilled version and are committed.

See `docs/conversation-notes.md` for how it works and how to change it.
