Implement the longest strictly-increasing subsequence in a file named
`solution.py`.

Contract (exact names):

- `lis_length(nums: list[int]) -> int` — length of the longest strictly
  increasing subsequence (a subsequence keeps the original order but may
  skip elements; equal values do not count as increasing). Empty input
  is 0.
- `lis(nums: list[int]) -> list[int]` — one valid subsequence whose
  length equals `lis_length(nums)` (any valid one is accepted). Empty
  input is `[]`.
